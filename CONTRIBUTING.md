# Contributing

Thank you for helping improve the Healthcare Firewall Migration Toolkit.

## Ways to help

- **Report a problem:** open an issue describing what is unclear, wrong or missing.
- **Share your experience:** open a **Field report** issue describing how you used a template (organization type and size, firewall vendors, what worked, what did not). Do not include patient data, internal IP addresses, passwords or anything else confidential.
- **Suggest a change:** open a pull request. Keep the language plain and vendor-neutral.

## Ground rules

- Never add protected health information or real configuration secrets to the repository.
- Keep templates usable by an organization with one IT person.
- By contributing, you agree that code contributions are released under the MIT License and content contributions (text, templates, `src/content.js`) under CC BY 4.0.
- Run `npm test` before opening a pull request.
